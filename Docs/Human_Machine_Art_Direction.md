# Human-Machine Art Direction

## Visual Intent

Project S uses a near-future human industrial military force. Units are operated machines and armored infantry, not alien organisms or clean futuristic toys. The field should read as functional, repaired, and built for prolonged combat.

## Shared Language

| Element | Direction |
|---|---|
| Base material | Gunmetal, worn steel, dark navy armor plates |
| Friendly technology | Cyan and cool-white power cores, blue status strips |
| Industrial markings | Sparse amber warning lamps, hazard stripes, panel seams |
| Silhouette | Readable top-down shape with a clear role at small scale |
| Lighting | Hard rim highlights and small emissive power points; no magical glow clouds |
| Team distinction | UI, health bars, and selection remain team-led; artwork stays faction-neutral |

| Worker | Utility walker | Tool arm and compact cargo frame |

| Tank | Tracked armor | Heavy hull and turret cannon |

| Swarm | Light drone | Small paired rotors and compact body |
| Medic | Field support walker | White medical panel and supply manipulators |

## Building Roles

| Building | Visual cue |
|---|---|
| Main Base | Large command deck and central cyan reactor |

| Spliter Production | Reinforced impact-tool fabrication rig |
| Auto Turret | Compact fixed cannon with tracking sensor |
| Speed Aura | Relay coil and circular field projector |
| Construction Site | Steel frame, crane arm, amber work lamps |
| Vehicle Factory | Wide armored hangar and vehicle service rails |
| Maintenance Bay | Repair gantry, tool racks, white service light |
| Signal Relay | Tall radar mast and directional antenna array |

## Application Rule

- Every playable unit and building prefab receives one dedicated texture file.
- A texture is used by one role only; completed buildings and construction sites remain separate assets.
- Texture changes preserve existing collider, sorting, health bar, fog visibility, selection, and gameplay component structure.
