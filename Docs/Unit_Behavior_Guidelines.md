# Unit Behavior Guidelines

## 문서 지위

이 문서는 Project S 유닛의 역할, 능력치 의도, 고유 행동, 명령 반응, 자동 전투 규칙을 정의하는 단일 기준 문서다.

- 유닛 특성, 고유 행동, 사거리, 추적, 거리 유지, 명령 우선순위를 구현하거나 변경하기 전에 반드시 이 문서를 먼저 갱신하고 참조한다.
- 코드, 프리팹, 테스트가 이 문서와 다르면 문서를 기준으로 차이를 해소한다.
- 공통 게임 방향은 `Docs/Project_S_Working_Game_Plan.md`를 따르며, 이 문서는 그중 유닛 행동을 구체화한다.
- 새 규칙은 기존 명령 생명주기, 자동 전투, 경로 탐색, 점유 정책을 우회하지 않고 상태 기반으로 연결한다.

## 명령 우선순위

유닛 고유 행동보다 플레이어와 AI가 내린 명령 의도가 우선한다.

| 우선순위 | 명령/상태 | 고유 행동 적용 |
|---|---|---|
| 1 | 새 직접 명령 | 이전 명령과 교전 상태를 즉시 중단한다. |
| 2 | `Move`, `Interact` | 적을 자동 획득하지 않으며 거리 유지나 근접 돌진도 실행하지 않는다. |
| 3 | `FocusAttack` | 지정 대상을 최우선으로 유지하면서 해당 유닛의 교전 거리 규칙을 적용한다. |
| 4 | `HoldPosition` | 사거리 안의 적만 공격하며 추격과 Ranger 후퇴를 모두 금지한다. |
| 5 | `AttackMove`, `Patrol` | 이동 목적을 유지하되 적 감지 시 고유 교전 규칙으로 전환한다. |
| 6 | `Idle` | 감지 거리 안의 적을 자동 획득해 고유 교전 규칙을 적용한다. |

- 명령 큐는 사용하지 않으며 새 명령이 기존 명령을 대체한다.
- `UnitCommandMode`는 장기 명령 의도, `UnitActionState`는 현재 실행 상태를 나타낸다.
- 직접 지정한 `FocusAttack` 대상은 자동 탐색 후보보다 항상 우선한다.
- 일반 이동 중에는 감지와 피격으로 교전하지 않는다.
- 자동 반격은 `Idle`에서는 감지 거리 안, `HoldPosition`에서는 공격 사거리 안에서만 허용한다.

## 공통 표적 규칙

자동 표적은 등록 기반 근접 후보 안에서 다음 순서로 선택한다.

```text
최근 자신을 공격한 대상
-> 전투 유닛
-> 일꾼
-> 방어 건물
-> 생산 건물
-> 본진 및 기타 건물
```

- 같은 우선순위에서는 거리와 위협도를 함께 사용하고, 작은 거리 변화만으로 대상을 바꾸지 않는다.
- 자동 획득 대상이 사망하거나 유지 거리 밖으로 나가면 현재 명령에 맞는 이동, 순찰, 대기 상태로 복귀한다.
- 고유 행동은 현재 `PriorityTarget` 하나만 사용하며 별도의 전역 대상 탐색을 수행하지 않는다.

## 시야 및 마지막 관측 정보

- 유닛 시야 반경은 각 유닛 프리팹의 `PrototypeUnitStatus.visionRadius`에서 조정한다.
- 기본 시야 반경은 Worker 6, Soldier 7, Spliter 7, Ranger 9, Tank 8, Striker 6, Swarm 5.5, Medic 10, Siege 8, Scout 11을 기준으로 한다.
- 적 유닛이나 건물이 현재 시야에 들어오면 그 위치를 마지막 관측 위치로 갱신한다.
- 관측한 적이 안개로 들어가면 실제 현재 위치를 노출하지 않고, 마지막 관측 위치만 미니맵에 약한 일반 마커로 표시한다.
- 적을 다시 관측하면 실제 마커로 복귀하고 마지막 관측 위치도 새 위치로 갱신한다. 적이 사망하거나 등록 해제되면 마지막 관측 마커를 제거한다.
- 마지막 관측 정보는 전투 표적 탐색이나 명령 대상 선정에는 사용하지 않으며 UI 전술 정보로만 사용한다.

## 능동 스킬 공통 규칙

- 능동 스킬은 공통 데이터 정의와 유닛별 실행 컴포넌트로 구성하며, 각 정의는 이름, 효과 유형, 쿨다운, 지속시간, 효과 수치를 가진다.
- 현재 최소 루프는 대상이 필요 없는 자기 강화형 스킬만 지원한다. 대상 지정, 해금 조건, 자원 소모, 연계 및 복합 효과는 후속 범위로 남긴다.
- 스킬은 즉시 실행하며 현재 `UnitCommandMode`, `UnitActionState`, 이동 목적지, `PriorityTarget`, 최신 명령 ID를 변경하지 않는다.
- 선택 HUD의 스킬 버튼 또는 `F` 단축키로 선택된 유닛들의 첫 번째 스킬을 실행한다. 일부 유닛만 실행 가능하면 가능한 유닛에는 적용하고 실패 수를 함께 안내한다.
- 쿨다운 중, 정의 누락, 사망 또는 비활성 상태에서는 실행하지 않고 HUD와 실행 컴포넌트에 실패 사유를 남긴다.
- AI는 능동 스킬을 자동으로 사용하지 않는다.

## 전투 시각 피드백

- 공격 적중, 피해, 사망, 능동 스킬 성공은 공통 `CombatFeedbackEvents`를 발행하며 전투 수치와 상태 판정은 변경하지 않는다.
- 공격 적중은 짧은 황색 파동, 피격은 작은 적색 파동, 사망은 더 크고 긴 소멸 파동, 능동 스킬은 청록색 강화 파동으로 구분한다.
- 피드백 렌더러는 미리 생성한 2D 라인 렌더러를 재사용하고, 동시 표시 상한에 도달하면 가장 오래된 효과를 재사용한다. 매 공격마다 새 오브젝트나 머티리얼을 생성하지 않는다.
- 아군 피드백은 항상 표시하고, 적 유닛과 적 건물의 피드백은 해당 위치가 현재 플레이어 시야에 있을 때만 표시한다. 마지막 관측 위치에는 전투 이펙트를 표시하지 않는다.
- 사운드와 화면 흔들림은 공통 이벤트의 후속 구독자로 확장할 수 있지만 현재 범위에서는 구현하지 않는다.

## 유닛 행동 기준

### Worker

- 핵심 역할: 자원 채집과 건설.
- 교전: 기본적으로 자동 전투 역할을 갖지 않는다.
- 이동: 채집, 반납, 건설 상호작용과 직접 이동 명령을 우선한다.
- 자동 자원 배정은 별도 `WorkerAutoAssignmentManager`가 활성화된 경우에만 `Idle` Worker에게 적용한다.
- 자동 배정된 Worker라도 플레이어 또는 AI의 새 직접 명령이 들어오면 자동 배정이 즉시 양보하며, `Interact` 중인 명령은 자동 관리자가 덮어쓰지 않는다.

### Soldier

- 핵심 역할: 전열을 유지하는 안정적인 기본 전투 유닛.
- 사거리: 근접 1.5, 감지 5를 기준으로 한다.
- 추적: 감지된 대상을 표준 재탐색 간격으로 추격하고 공격 사거리 경계에서 정지한다.
- 거리 유지: 별도 후퇴나 과도한 파고들기를 사용하지 않는다.
- 의도: 다른 유닛 행동을 비교할 수 있는 기준점이며, 명령 전환과 표적 유지가 예측 가능해야 한다.

### Spliter

- 핵심 역할: 밀집한 적에게 피해를 분산시키는 근거리 광역 전투 유닛.
- 사거리: 공격 1.4, 감지 5를 기준으로 한다.
- 광역: 주 대상을 반드시 포함하고 반경 2 안에서 가까운 적을 최대 3개까지 공격한다.
- 추적: Soldier와 같은 안정적인 접근 규칙을 사용한다.
- 의도: 단일 대상 화력보다 적 무리가 뭉친 상황에서 효율이 분명해야 한다.

### Ranger

- 핵심 역할: 긴 사거리에서 안전 거리를 유지하는 원거리 지원 유닛.
- 사거리: 공격 6, 감지 8을 기준으로 한다.
- 후퇴 시작: 대상과의 실제 충돌체 간 거리가 공격 사거리의 45%보다 가까워지면 후퇴한다.
- 후퇴 종료: 거리가 공격 사거리의 72% 이상 확보되면 후퇴를 끝내고 재교전한다.
- 추적: 대상이 공격 사거리 밖이면 추격하고, 안전 거리와 공격 사거리 사이에서는 정지해 공격한다.
- 예외: `HoldPosition`에서는 후퇴하지 않고 현재 위치에서 사거리 안 대상만 공격한다.
- 의도: 근접 압박에 취약하지만 거리 관리에 성공하면 지속 화력을 제공한다.

### Tank

- 핵심 역할: 느린 이동을 대가로 장거리 단일 대상 화력을 제공하는 중화력 유닛.
- 능력치 기준: 체력 260, 공격력 26, 공격 사거리 5.5, 감지 7, 공격 속도 0.55, 이동 속도 2.
- 추적: 긴 사거리 경계에서 일찍 정지하며, 별도 후퇴 행동은 사용하지 않는다.
- 의도: 진입과 재배치는 느리지만 사격 위치를 확보하면 높은 한 발 피해를 제공한다.

### Striker

- 핵심 역할: 빠르게 접근해 목표에게 밀착하는 근접 돌격 유닛.
- 사거리: 공격 0.8, 감지 4를 기준으로 한다.
- 추적: 표준 유닛보다 자주 목표 경로를 갱신하고, 공격 사거리의 80% 안까지 접근한 뒤 공격한다.
- 거리 유지: 후퇴하지 않으며 대상이 유효한 동안 공격 사거리 진입을 우선한다.
- 능동 스킬: `Overdrive`는 대상 없이 즉시 실행되며 4초 동안 이동 속도를 50% 증가시킨다. 쿨다운은 12초다.
- 의도: 빠른 이동과 높은 공격 빈도로 Tank 같은 느린 목표를 압박한다.

### Swarm

- 핵심 역할: 여러 개체 생산을 전제로 적에게 달라붙어 전열을 흔드는 근접 군집 유닛.
- 사거리: 공격 1.1, 감지 4.5를 기준으로 한다.
- 추적: 표준 유닛보다 자주 목표 경로를 갱신하고, 공격 사거리의 85% 안까지 접근한 뒤 공격한다.
- 거리 유지: 후퇴하지 않으며 개별 개체는 기존 점유 및 분산 경로 규칙을 그대로 따른다.
- 의도: 개별 전투력보다 수량과 포위 압박에서 가치가 드러나야 한다.

### Medic

- 핵심 역할: 아군과 함께 이동하며 생존하고 시야를 제공하는 비전투 지원 유닛.
- 능력치 기준: 체력 90, 공격력 0, 공격 사거리 0, 감지 0, 공격 속도 0, 이동 속도 3.6, 시야 10.
- 교전: 자동 표적 획득, 추격, 공격, 반격을 수행하지 않는다. `FocusAttack` 명령을 받아도 공격 컴포넌트가 없으므로 피해를 주지 않는다.
- 이동: 직접 이동, 대기, 순찰 등 기존 이동 명령과 경로 탐색만 사용한다.
- 지원 범위: 현재 단계에서는 치료, 보호막, 버프 등 별도 지원 시스템을 만들지 않는다.
- 의도: 전투 화력을 늘리지 않고 부대 이동과 정찰에서 선택 가치를 제공한다.

### Siege

- 핵심 역할: 느린 재배치를 대가로 건물에 강한 한 발 피해를 제공하는 장거리 포격 유닛.
- 능력치 기준: 체력 180, 공격력 36, 공격 사거리 8.5, 감지 9.5, 공격 속도 0.45, 이동 속도 1.7, 시야 8.
- 교전: 기존 단일 대상 공격 시스템과 공통 표적 우선순위를 사용하며, 별도 공성 모드나 신규 투사체 시스템을 만들지 않는다.
- 추적: `Artillery` 교전 프로필로 사거리 경계에서 정지하고, 별도 후퇴 행동은 사용하지 않는다.
- 대건물 운용: 건물 공격은 기존 `FocusAttack` 및 공격 명령으로 지정한다. 별도 피해 배율이나 자동 건물 우선 탐색은 추가하지 않는다.
- 의도: 호위와 시야 확보가 필요하지만 사격 위치를 잡으면 건물을 빠르게 압박한다.

### Scout

- 핵심 역할: 빠른 이동과 넓은 시야로 전장을 확인하는 경량 원거리 전투 유닛.
- 능력치 기준: 체력 55, 공격력 5, 공격 사거리 4.5, 감지 7, 공격 속도 1.2, 이동 속도 4.8, 시야 11.
- 교전: 기존 단일 대상 원거리 공격 시스템만 사용하며 별도 회피, 은신, 탐지 시스템을 만들지 않는다.
- 추적: 표준 교전 프로필을 사용하며 공격 사거리 밖의 대상을 추격하고 사거리 경계에서 정지한다.
- 거리 유지: Ranger의 자동 후퇴 규칙을 사용하지 않는다.
- 의도: 전투 지속력과 화력은 낮지만 정찰, 측면 확인, 빠른 합류에 강점을 가진다.

## 상태 전환 기준

```text
대상 없음 -> 기존 명령 상태
대상 감지 -> ChasingTarget
공격 진입 거리 도달 -> AttackingTarget
Ranger 최소 거리 침범 -> RetreatingFromTarget
Ranger 안전 거리 회복 -> AttackingTarget 또는 ChasingTarget
대상 소멸/이탈 -> 기존 명령 재개
```

- 후퇴와 추격 모두 `UnitPathAgent`를 사용해 장애물, 점유 셀, 요청 스케줄러 정책을 유지한다.
- 경로 재계산은 기존 간격과 지터를 사용하며 Striker와 Swarm만 더 짧은 간격 배율을 적용한다.
- 고유 행동 판단은 현재 대상과 현재 거리만 사용하며 매 프레임 전역 탐색을 추가하지 않는다.

## 쉬운 AI 운용 기준

- 기본 전투 생산은 Soldier를 중심으로 하며, 전투 유닛이 5기 이상 모인 뒤 성공한 전투 생산 5회마다 Ranger와 Striker를 번갈아 한 기씩 시도한다.
- 기본 쉬운 AI는 Tank, Spliter, Swarm을 생산하지 않는다. 지원 유닛 생산이 자원, 보급, 생산 건물 조건 때문에 불가능하면 Soldier 생산을 다시 시도한다.
- 최초 공격은 경기 시작 후 90초 이상 지난 뒤, 전투 유닛 7기 이상이 모였을 때만 시작한다. 이후 공격 명령도 기존 18초 이상의 간격을 유지한다.
- 연구는 전투 유닛 6기 이상과 연구 비용 외 미네랄 200, 가스 50의 여유 자원을 동시에 확보했을 때만 진행한다.
- 연구 순서는 Weapon Calibration, Mobility Tuning이며 각 연구는 한 번만 완료한다. 앞 연구가 완료되기 전에는 다음 연구를 시작하지 않는다.
- 생산과 연구 실패는 기존 생산 큐와 연구 컴포넌트의 자원 및 보급 검증 결과를 존중하며, 실패한 요청 때문에 별도 자원 차감이나 상태 전환을 만들지 않는다.

## 변경 절차

1. 이 문서에서 역할과 수치 의도를 먼저 갱신한다.
2. 전술 프로필, 상태 전환, 프리팹 능력치를 구현한다.
3. 명령 우선순위와 기존 자동 전투 회귀 테스트를 함께 확인한다.
4. 즉시 실행하지 못한 장면 검증은 `Docs/Project_S_Verification_Backlog.md`에 추가한다.
