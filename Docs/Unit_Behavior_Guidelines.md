# Unit Behavior Guidelines

## 문서 목적

이 문서는 Project S의 각 유닛에 대한 기본 행동 요령을 정리하기 위한 작업 문서다.

초기 목적은 유닛별 역할과 행동 기준을 먼저 명확히 하여, 이후 자동 전투, AI 명령, 플레이어 조작 반응, 밸런스 조정으로 옮기기 쉽게 만드는 것이다.

## 전투 명령 상태 정책

| 명령 | 적 감지 | 추격 | 복귀/완료 |
|---|---|---|---|
| `Idle` | 감지 거리 안의 적을 자동 획득한다. | 적이 감지 거리 안에 있는 동안 추격/공격한다. | 대상이 사망하거나 감지 거리 밖으로 벗어나면 `Idle`로 복귀한다. |
| `HoldPosition` | 감지 거리 안의 적을 확인한다. | 사거리 밖의 적은 추격하지 않는다. | 사거리 밖 대상은 버리고 `HoldingPosition`을 유지한다. |
| `AttackMove` | 이동 중 감지 거리 안의 적을 자동 획득한다. | 적이 감지 거리 안에 있는 동안 추격/공격한다. | 대상이 사라지면 원래 공격 이동 목적지로 복귀하고, 도착하면 `Idle`이 된다. |
| `Patrol` | 순찰 중 감지 거리 안의 적을 자동 획득한다. | 적이 감지 거리 안에 있는 동안 추격/공격한다. | 대상이 사라지면 순찰 경로로 복귀한다. |
| `FocusAttack` | 지정 대상만 공격한다. | 감지 거리와 무관하게 지정 대상을 추격한다. | 대상이 사망하거나 사라지면 `Idle`이 된다. |

- 명령 큐는 사용하지 않고, 새 명령이 들어오면 기존 명령은 중단한다.
- `ActionState`는 현재 실행 상태이고, 장기 정책은 `UnitCommandMode`를 기준으로 판단한다.
- `HoldPosition`은 일반 RTS 감각의 제자리 방어 명령으로 취급한다.
- 자동 반격은 `Idle`에서는 감지 거리 안의 공격자에게만 반응하고, `HoldPosition`에서는 공격 사거리 안의 공격자에게만 반응한다.

## 작성 기준

- MVP 범위의 유닛을 우선 정리한다.
- 유닛 수를 늘리기보다 역할이 분명한 1종의 일꾼과 3종의 전투 유닛을 먼저 다룬다.
- 행동 요령은 구현 가능한 규칙으로 옮길 수 있을 정도로 구체화한다.
- 상성은 절대 승패가 아니라 위치, 수량, 컨트롤에 따라 뒤집힐 수 있게 둔다.

## MVP 기준 유닛

현재 문서 기준상 MVP 유닛은 다음 4종으로 본다.

| 유닛 | 역할 |
|---|---|
| Worker | 자원 채집 / 건설 담당 |
| Soldier | 기본 전투 유닛 |
| Spliter | 빠른 돌격 유닛 역할로 추정 |
| Ranger | 원거리 유닛 |

## 공통 명령 및 교전 규칙

아래 규칙은 공격이 가능한 모든 유닛에 공통으로 적용한다.

### 직접 공격 명령

- 플레이어 또는 AI가 특정 적 유닛을 공격 타겟으로 지정한 경우, 해당 타겟을 최우선 적으로 설정한다.
- 최우선 타겟이 생존해 있고 공격 가능한 상태라면, 주변의 다른 적보다 해당 타겟을 먼저 추적하고 공격한다.
- 최우선 타겟이 사망하거나 유효하지 않은 상태가 되면, 유닛은 현재 명령 상태에 맞는 다음 행동으로 전환한다.

### 경계 이동

플레이어 또는 AI가 `A`키 입력 후 이동 명령을 내리는 행동을 경계 이동으로 명명한다.

- 경계 이동 중인 공격 가능 유닛은 목적지로 이동하면서 전투 개시 조건을 감시한다.
- 적이 공격 사거리 안에 들어오면 즉시 전투 상태로 전환한다.
- 경계 이동 중 피격 당하면 즉시 전투 상태로 전환한다.
- 전투 상태로 전환된 뒤에는 현재 감지된 적 또는 공격자를 우선 대상으로 삼아 교전한다.

### 일반 이동

일반 이동은 공격 의도가 없는 위치 이동 명령으로 취급한다.

- 일반 이동 중인 유닛은 목표 지점 도착을 최우선으로 한다.
- 일반 이동 중에는 적이 사거리 안에 감지되어도 전투 상태로 전환하지 않는다.
- 일반 이동 중 피격 당해도 전투 상태로 전환하지 않고 목표 설정 지점까지 이동한다.
- 목표 지점에 도착한 뒤에는 이후 기본 대기 규칙 또는 별도 명령 규칙을 따른다.

## 유닛별 행동 요령 템플릿

각 유닛의 기본 행동 요령은 아래 형식으로 정리한다.

```text
유닛명:
- 핵심 역할:
- 기본 행동:
- 전투 시 우선순위:
- 이동/포지셔닝:
- 피해야 할 행동:
- AI가 사용할 때의 행동:
- 플레이어가 사용할 때의 의도:
```

## 작성 예시

```text
Ranger:
- 핵심 역할: 긴 사거리로 안전한 위치에서 피해를 누적하는 원거리 전투 유닛
- 기본 행동: 적과 거리를 유지하며 사거리 안의 대상을 공격한다.
- 전투 시 우선순위: 접근 중인 빠른 돌격 유닛 또는 체력이 낮은 전투 유닛을 우선 공격한다.
- 이동/포지셔닝: 전방 유닛 뒤에 위치하고, 적 근접 유닛이 접근하면 후퇴를 우선한다.
- 피해야 할 행동: 가장 앞에서 교전을 시작하거나, 혼자 적진 깊게 진입하지 않는다.
- AI가 사용할 때의 행동: Soldier 뒤에서 화력을 지원하고, 근접 압박을 받으면 본대 쪽으로 물러난다.
- 플레이어가 사용할 때의 의도: 거리 유지와 집중 공격 컨트롤의 가치를 느끼게 한다.
```
