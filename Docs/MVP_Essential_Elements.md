# MVP Essential Elements

## 문서 목적

이 문서는 1차 프로토타입 단계에서 반드시 구현해야 하는 MVP 필수 요소를 정의한다.

목표는 완성도 높은 RTS 전체 게임이 아니라, 다음 핵심 질문을 검증할 수 있는 최소 플레이 가능 버전을 만드는 것이다.

```text
자원을 모으고, 기지를 짓고, 병력을 생산해서, 실시간 전투로 적을 섬멸하는 흐름이 실제로 재미있는가?
```

## MVP 개발 목표

- 주 장르: 전략 게임
- 보조 장르: RTS
- 시점: 2D 탑다운
- 플랫폼: PC 우선 개발, 모바일은 추후 대응
- 플레이 형식: 스타크래프트와 유사한 1대1 RTS 매치
- 1차 콘텐츠: 플레이어 vs AI 1대1 매치
- 승리 목표: 적 섬멸
- 권장 플레이 시간: 15~25분
- 최대 플레이 시간: 40분 미만

## MVP 범위 요약

```text
플레이어 1명 vs AI 1명
진영 1개
테스트 맵 1개
자원 1종
본진 건물 1종
자원 채집 유닛 1종
전투 유닛 최소 3종
생산 건물 1~2종
간단한 AI
승패 판정
기본 UI
```

## 필수 구현 요소

| 영역 | 필수 구현 내용 | 목적 |
|---|---|---|
| 카메라 | 2D 탑다운, 이동, 줌 | RTS의 기본 시야와 조작 감각 확보 |
| 입력 | 마우스 선택, 드래그 박스 선택, 우클릭 이동/공격 | 유닛 지휘의 기본 경험 구현 |
| 맵 | 1개 테스트 맵 | 자원, 기지, 전투 동선 검증 |
| 자원 | 최소 1종 자원 | 생산과 확장의 기반 |
| 일꾼 | 자원 채집, 복귀, 반복 채집 | 자원 생산 루프 구현 |
| 건물 | 본진, 생산 건물 | 기지 운영의 기본 구조 |
| 유닛 생산 | 건물에서 유닛 생산 | 자원 소비와 병력 확보 루프 구현 |
| 전투 유닛 | 최소 3종 | 상성과 전투 판단 검증 |
| 전투 | 자동 공격, 사거리, 체력, 공격력 | RTS 전투의 최소 규칙 |
| 상성 | 간단한 유닛 간 강약 관계 | 전략적 선택의 이유 제공 |
| AI | 채집, 생산, 공격 타이밍 | 1대1 매치 성립 |
| 승패 | 적 주요 건물 파괴 또는 적 전멸 | 매치 종료 조건 |
| UI | 자원 표시, 선택 정보, 생산 버튼 | 플레이어 의사결정 지원 |

## 유닛 최소 구성

초기 MVP에서는 유닛 수를 늘리기보다 역할이 분명한 3종을 먼저 만든다.

| 유닛 유형 | 역할 | 기획 의도 |
|---|---|---|
| 기본 전투 유닛 | 평균적인 비용, 체력, 공격력 | 전투의 기준점 |
| 빠른 돌격 유닛 | 빠른 이동, 근접 또는 기습 역할 | 위치 선정과 타이밍 판단 유도 |
| 원거리 유닛 | 긴 사거리, 낮은 체력 | 거리 유지와 보호 전술 유도 |

## 건물 최소 구성

| 건물 유형 | 역할 |
|---|---|
| 본진 건물 | 일꾼 생산, 자원 저장, 주요 승패 조건 |
| 기본 생산 건물 | 전투 유닛 생산 |
| 보조 생산 또는 기술 건물 | 선택 사항, 필요 시 유닛 해금 또는 강화 담당 |

## AI 최소 요구 사항

AI는 뛰어난 전략가일 필요는 없다. MVP 단계에서는 플레이어가 기본 RTS 루프를 테스트할 수 있을 정도면 충분하다.

- 일꾼을 생산하거나 유지한다.
- 자원을 채집한다.
- 생산 건물에서 유닛을 만든다.
- 일정 병력이 모이면 공격한다.
- 본진 또는 주요 건물을 방어한다.
- 승패 조건에 반응한다.

## UI 최소 요구 사항

- 현재 보유 자원 표시
- 선택한 유닛 또는 건물 정보 표시
- 체력 표시
- 생산 가능한 유닛 버튼
- 생산 진행 상태
- 승리/패배 결과 표시

## MVP에서 제외할 요소

| 제외 요소 | 제외 이유 |
|---|---|
| 복잡한 세계관 | 시스템 재미 검증 후 결정 가능 |
| 고품질 아트 | 임시 모델과 색상 블록으로 충분 |
| 다수 종족 | 밸런스와 제작 범위가 과도하게 커짐 |
| 캠페인 | AI 1대1 검증 이후가 적절 |
| 멀티플레이 | 네트워크 개발 부담이 큼 |
| 모바일 조작 최적화 | PC 조작 완성 후 대응 |
| 고급 업그레이드 트리 | 기본 루프 검증 후 확장 |
| 안개 전쟁 | 초기 필수는 아니며 후속 단계에서 검토 |

## MVP 완료 기준

아래 조건을 만족하면 1차 MVP를 완료한 것으로 본다.

- 플레이어가 유닛을 선택하고 명령할 수 있다.
- 일꾼이 자원을 반복 채집할 수 있다.
- 자원을 사용해 건물 또는 유닛을 생산할 수 있다.
- 최소 3종의 전투 유닛이 서로 다른 역할을 가진다.
- 플레이어와 AI가 각각 기지를 운영한다.
- AI가 병력을 생산하고 공격한다.
- 전투를 통해 승패가 결정된다.
- 1회의 매치가 40분을 넘기지 않는 구조를 가진다.
