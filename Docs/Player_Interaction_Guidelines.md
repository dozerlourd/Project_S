# Player Interaction Guidelines

## 문서 목적

이 문서는 Project S의 플레이어 구성 요소와 기본 상호작용을 정리한다.

스타크래프트 계열 RTS의 핵심 조작을 참고하되, MVP 단계에서는 선택, 이동, 공격 이동, 집중 공격, 정지, 위치 고수, 순찰, 컨트롤 그룹을 우선 구현 대상으로 둔다.

## 플레이어 구성 요소

| 요소 | 역할 |
|---|---|
| PlayerUnitCommandController | 플레이어 입력을 해석하고 선택 유닛에 명령을 전달한다. |
| UnitCommandAgent | 유닛의 현재 명령 상태를 관리한다. |
| UnitPathAgent | 맵 기반 A* 경로를 따라 유닛을 이동시킨다. |
| PrototypeUnitStatus | 팀, 이동 타입, 공격 사거리, 이동 속도 등 유닛 판정 데이터를 제공한다. |
| MapPathfinder | 맵 셀과 이동 가능 여부를 기준으로 경로와 클릭 좌표를 계산한다. |

## 기본 상호작용

| 입력 | 상호작용 | Project S 처리 |
|---|---|---|
| 좌클릭 | 유닛 선택 | 플레이어 팀 지상 유닛을 선택한다. |
| Shift + 좌클릭 | 선택 추가 | 현재 선택에 유닛을 추가한다. |
| 우클릭 지면 | 일반 이동 | 적을 무시하고 목적지까지 이동한다. |
| 우클릭 적 | 집중 공격 | 지정한 적을 최우선 타겟으로 설정한다. |
| A + 좌클릭 지면 | 공격 이동 | 목적지로 이동하면서 사거리 내 적을 감지하면 교전한다. |
| S | 정지 | 현재 명령과 경로를 취소한다. |
| H | 위치 고수 | 이동하지 않고 사거리 안의 적만 대응한다. |
| P + 좌클릭 지면 | 순찰 | 현재 위치와 지정 위치를 오가며 적을 감지한다. |
| Ctrl + 숫자 | 컨트롤 그룹 지정 | 현재 선택 유닛을 해당 그룹에 저장한다. |
| 숫자 | 컨트롤 그룹 선택 | 저장된 그룹을 다시 선택한다. |
| Shift + 숫자 | 컨트롤 그룹 선택 추가 | 저장된 그룹을 현재 선택에 추가한다. |
| Shift + 명령 | 명령 큐 | 현재 명령 뒤에 추가 명령을 예약한다. |

## 구현 메모

- 일반 이동은 적 감지나 피격으로 전투 상태에 들어가지 않는 이동 명령으로 본다.
- 공격 이동은 경계 이동의 기본 형태로 사용한다.
- 집중 공격은 지정 타겟을 최우선 대상으로 삼는다.
- 현재 MVP 구현은 타겟 지정, 추적, 사거리 내 정지, 방향 전환까지 담당한다.
- 실제 피해 적용, 공격 쿨타임, 투사체, 사망 처리는 전투 시스템 구현 단계에서 `UnitCommandAgent`에 연결한다.
